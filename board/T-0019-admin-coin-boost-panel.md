## 任務

將管理員面板中「賺錢／收益加成」功能移至「管理員活動」區域，並調查修復使用者點擊開啟後沒有反應的問題。保留原有全服及指定玩家加成能力與權限限制。

## 範圍與禁止

- 只動：管理員面板相關導覽、收益加成 UI、事件綁定及其必要的狀態載入／呼叫接線。
- 不要動：其他管理員活動、玩家貨幣資料、加成倍率規則或權限政策，除非修復此功能必須且經棒子確認。
- 不得將管理員權限檢查移至純前端或放寬既有權限。
- 不得只修正按鈕外觀；必須確認面板能實際開啟並完成既有操作。

## 驗收條件

- [ ] 「賺錢／收益加成」入口位於「管理員活動」區域，舊位置不再重複顯示。
- [ ] 點擊入口可正常開啟、關閉及重新開啟面板，無 JS 例外或無反應狀況。
- [ ] 管理員可依既有功能設定全服及單一玩家倍率；非管理員無法呼叫或使用管理操作。
- [ ] 設定後 UI 顯示值、實際每秒收益及重新載入後狀態一致。
- [ ] 完成事件綁定／權限相關測試及管理員瀏覽器回歸；未取得管理員正式帳號驗證時明確標示待棒子驗收。
