## 任務

新增特殊道具「時序結晶」。玩家合成並持有後，可主動啟用一次待生效效果，使下一次由玩家召喚的天氣持續時間延長 20%。

## 範圍與禁止

- 道具名稱：時序結晶。
- 道具簡介必須完全使用：「可使下個天氣延長20%時間」。
- 合成材料只有三種骰子，各 1 顆：時序骰子 ×1、虛空骰子 ×1、故障骰子 ×1；不需要金錢或其他材料。
- 道具使用冷卻時間為 1 小時；合成後持有道具可重複使用，依冷卻限制，不是每次啟用都消耗道具本體。
- 啟用後效果等待下一次玩家召喚的天氣，延長該次天氣原定持續時間 20%。
- 適用所有玩家召喚的天氣，包含雨、雪、打雷、水晶、地獄及故障天氣；不得依天氣類型漏掉或硬編特例。
- 管理員召喚的天氣不受時序結晶影響，且不得消耗待生效效果。
- 管理員天氣活動進行中，玩家按下時序結晶時顯示「活動進行中...」；不得扣材料、消耗道具效果或啟動冷卻。
- 管理員天氣期間若玩家先前已成功啟用、效果仍在等待，該效果保留，直到下一次玩家召喚天氣才觸發；管理員天氣本身不可被延長。
- 由伺服器權威判定天氣召喚來源、延長秒數、待生效狀態及一小時冷卻；不能只改前端倒數或讓不同玩家看到不同結束時間。
- 使用與天氣召喚需處理併發、重複請求及重試冪等性；同一個待生效效果最多只能套用一次。
- 優先沿用現有道具工坊、天氣系統及伺服器交易流程；先檢查目前配方、道具 ID、weather state／RPC 結構，再按既有架構實作。
- 不得改動天氣轉換器既有功能、每小時冷卻、管理員天氣控制、既有玩家存檔或其他道具配方。
- 不新增高頻 Supabase 輪詢或每次擲骰寫入；盡量使用既有天氣狀態同步與原子 RPC。
- 遊戲版本與 PWA cache 依專案規範同步遞增 0.01。

## 驗收條件

- [ ] 道具工坊顯示「時序結晶」，簡介精確為「可使下個天氣延長20%時間」。
- [ ] 配方精確為時序骰子 ×1、虛空骰子 ×1、故障骰子 ×1，沒有金錢及其他材料。
- [ ] 合成交易原子且冪等，材料只扣一次，重複請求不會重複發放。
- [ ] 持有者可啟用時序結晶，成功啟用後冷卻 1 小時。
- [ ] 成功啟用後，下一次玩家召喚的雨、雪、打雷、水晶、地獄或故障天氣，持續時間精確增加原始時間的 20%。
- [ ] 管理員召喚天氣不套用延長，且不消耗待生效效果。
- [ ] 管理員天氣進行中點擊時顯示「活動進行中...」，不扣除任何材料／道具、不啟動冷卻。
- [ ] 若待生效效果先於管理員天氣啟用，管理員天氣結束後仍保留，直到下一次玩家召喚天氣才套用一次。
- [ ] 兩名玩家同時召喚、重複點擊或網路重試時，效果不重複套用，伺服器狀態與全服顯示一致。
- [ ] 天氣轉換器、管理員天氣、既有天氣倒數與其他道具回歸測試通過。
- [ ] 不增加不必要的 Supabase 請求／輪詢；版本與 PWA cache 同步。
- [ ] GitHub Pages 部署完成並確認線上版本包含新道具。
