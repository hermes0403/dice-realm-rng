## 任務

建立由伺服器權威狀態及可信事件維護的玩家統計投影、排行榜與公開紀錄，並限制玩家只能更新允許的個人資料欄位。

## 範圍與禁止

- 只動：
  - player_profiles 權威統計欄位維護、排行榜查詢、玩家名稱更新 RPC、稀有擲骰公告、合成／藥水／寵物歷史展示及在線狀態輔助欄位。
- 不要動：
  - 遊戲交易本身、成就／每日任務邏輯或 legacy 資料最終清理。
  - 不得信任客戶端提交的統計、排行榜分數、稀有事件或其他公開紀錄內容。
  - 舊 profile 統計未核對前只能標示歷史／待核對，不得混入可信排名。
- 實作前依 Board 規則取得本任務專用 branch／worktree 的人類授權；不得自行建立。

## 驗收條件

- [ ] 玩家不能直接修改權威統計、排行榜分數或伺服器產生的公開事件。
- [ ] 統計投影由可信交易／事件維護，排行榜查詢只讀取可信欄位。
- [ ] 玩家名稱更新由伺服器驗證允許欄位及內容，不得藉此修改其他 profile 欄位。
- [ ] 稀有公告及歷史紀錄只能由伺服器可信事件產生，不能由客戶端偽造。
- [ ] 補上直接 UPDATE 權限拒絕、跨帳號、偽造事件及公開查詢範圍測試。
- [ ] 補上未授權、跨帳號、重複請求、併發及 rollback 測試；依任務範圍選用適用案例。
- [ ] git diff --check exit 0；相關測試指令與 exit code 記錄於任務紀錄。
