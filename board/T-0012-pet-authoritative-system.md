## 任務

將寵物合成、個體屬性、裝備、技能觸發、出售及被動收益改為伺服器權威管理；寵物效果須與擲骰核心效果讀取／消耗契約一致。

## 範圍與禁止

- 只動：
  - fusePets()、equipPet()、寵物生成／UID／稀有度／變異／重量、技能次數與上限、自動出售、被動收益結算及寵物事件。
- 不要動：
  - 擲骰核心本體、一般骰子／手套／藥水／天氣交易、成就系統整體實作。
  - 不接受客戶端指定寵物生成結果、屬性、技能觸發次數、收益時間或出售價值。
  - 舊寵物未核對資料只可作歷史顯示，不得直接提供權威加成、出售或收益。
- 實作前依 Board 規則取得本任務專用 branch／worktree 的人類授權；不得自行建立。

## 驗收條件

- [ ] 寵物合成成本、隨機生成、UID、屬性與持有權由伺服器決定並原子提交。
- [ ] 裝備切換、技能觸發及每日上限由伺服器驗證；擲骰核心能讀取可信寵物效果。
- [ ] 被動收益依資料庫時間及伺服器維護的 last_income_at 結算，具上限與冪等保護。
- [ ] 寵物出售及自動出售只依伺服器資產與規則計算，不接受客戶端估值。
- [ ] legacy 寵物未核對資料不會自動轉為權威寵物或收益。
- [ ] 補上未授權、跨帳號、重複請求、併發及 rollback 測試；依任務範圍選用適用案例。
- [ ] git diff --check exit 0；相關測試指令與 exit code 記錄於任務紀錄。
