## 任務

在手套工坊新增兩副可用遊戲內金錢購買的手套，並由伺服器驗證價格與購買交易。

## 範圍與禁止

- 新增「虛空手套」：運氣 +35%、速度 +33%、價格 $5B（5,000,000,000）。
- 新增「星軌手套」：運氣 +38%、速度 +36%、價格 $18B（18,000,000,000）。
- 新手套使用新的唯一 ID（預定 g8、g9）；先確認未被其他資料或存檔用途占用。
- 手套工坊顯示正確名稱、運氣、速度與科學記號價格；購買成功後立即裝備，既有切換裝備方式不變。
- 更新 Supabase `purchase_glove` RPC 的伺服器端價格白名單；不得只修改前端商品資料。
- 保留既有 g0–g7 手套、價格、加成、天氣轉換器與舊玩家持有資料，不重設或覆寫任何既有裝備。
- 確認存檔正規化會保留新 ID，且 `luck()`、`speed()` 會讀取新手套加成；仍遵守現有 500% 上限。
- 購買交易必須由伺服器原子扣款、授予手套並更新裝備；不足額、重複請求及併發購買不得重複扣款或重複發放。
- 不新增資料表、不新增高頻 Supabase 輪詢、不改動骰子抽取機率或其他經濟規則。
- 遊戲版本與 PWA cache 依專案規範同步遞增 0.01。

## 驗收條件

- [ ] 手套工坊顯示虛空手套：運氣 +35%、速度 +33%、價格 $5B。
- [ ] 手套工坊顯示星軌手套：運氣 +38%、速度 +36%、價格 $18B。
- [ ] 伺服器只接受兩副新手套的指定價格；前端不能指定或覆寫價格。
- [ ] 金額足夠時購買成功、正確扣款並立即裝備。
- [ ] 金額不足、重複點擊、重試與併發請求均不會重複扣款或重複發放。
- [ ] 新手套加成正確影響運氣與速度，並遵守 500% 上限。
- [ ] 舊手套、既有持有資料、天氣轉換器與雲端存檔回歸測試通過。
- [ ] 版本與 PWA cache 同步遞增；不新增不必要的 Supabase 請求。
- [ ] GitHub Pages 部署完成並確認線上版本包含兩副新手套。
