## 任務

實作登入雲端時三項已核准純個人偏好的沿用與同步。偏好只控制操作便利性，不構成遊戲資產、權威結果或伺服器授權。

## 範圍與禁止

- 只動：
  - 擲骰背包自動出售清單、藥水材料自動添加設定、天氣召喚自動添加清單。
  - 雲端偏好讀取／更新及缺漏欄位初始化。
- 不要動：
  - 任何其他 LocalStorage 欄位、離線進度／資產、遊戲狀態、擲骰機率、售價、材料數量、天氣點數或其他權威運算。
  - 雲端已有值優先；僅缺少的白名單欄位可從離線純個人設定補入。不得整份搬移設定物件。
- 實作前依 Board 規則取得本任務專用 branch／worktree 的人類授權；不得自行建立。

## 驗收條件

- [ ] 同步欄位僅限上述三項，採明確 allowlist；未知欄位拒絕或忽略。
- [ ] 雲端已存在的值優先；只初始化缺少欄位，不覆蓋既有雲端選擇。
- [ ] 偏好更新只能修改呼叫者自己的偏好，後端驗證欄位型別與允許值。
- [ ] 偏好不能改變隨機結果、資產數量、價格、容量、效果強度或其他權威狀態。
- [ ] 登入同步不會傳送離線遊戲進度或整份存檔。
- [ ] 補上未授權、跨帳號、重複請求、併發及 rollback 測試；依任務範圍選用適用案例。
- [ ] git diff --check exit 0；相關測試指令與 exit code 記錄於任務紀錄。
