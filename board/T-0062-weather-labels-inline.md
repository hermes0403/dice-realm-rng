## 任務

當全服同時存在兩種天氣時，天氣狀態區必須在同一行顯示兩個各自獨立的完整名稱，例如「水晶天氣」「雨天氣」並排；不得再顯示合併字串「水晶＋雨」或「水晶、雨」。單一天氣維持原本顯示方式。

## 範圍與禁止

- 只調整天氣狀態列的名稱呈現、必要 CSS、快取版本及對應測試。
- 不更動天氣觸發條件、持續時間、機率、全服同步、天氣效果、骰子加成或資料庫。
- 保留倒數計時、天氣圖示與各天氣原有配色；多天氣時可隱藏獨立總圖示以確保手機版同列容納兩個名稱及倒數。
- 不更動其他頁面文字、排版或功能。

## 驗收條件

- [ ] 同時存在水晶與雨時，顯示「水晶天氣」及「雨天氣」兩個獨立標籤，且在同一行。
- [ ] 標籤依伺服器天氣順序顯示，保留各自顏色，不以加號或頓號合併。
- [ ] 單一天氣仍顯示原本單一天氣名稱與圖示。
- [ ] 手機寬度下兩個標籤與倒數仍在同一行，不遮擋或截斷文字。
- [ ] 新增回歸測試涵蓋雙天氣、單天氣、重複及未知天氣值。
- [ ] 執行指定 Node 測試、相關語法檢查及 git diff --check 並通過。
