## 任務

修正藥水工坊「自動添加」：玩家選取藥水後，擲中該藥水配方所需骰子時，自動將骰子保留為藥水材料，直到達到配方需求數量；達標後藥水合成按鈕可正常啟用。

## 範圍與禁止

- 只動：擲骰後藥水材料自動收集、藥水材料存檔正規化。
- 不要動：藥水配方、藥水效果、玩家自動出售偏好、其他擲骰副作用。
- 不可直接修改 main；目前只提交 work/chazi。

## 驗收條件

- [x] 自動添加以玩家選取藥水的配方為準。
- [x] 每種骰子只收集到所選藥水配方實際需要的數量；已在背包與材料欄的數量都計入。
- [x] 超出配方需求後，後續骰子依玩家原本自動出售設定處理。
- [x] 取消原本固定最多 4 顆材料的限制，雲端載入不再截斷較大配方材料。
- [x] 合成可使用自動添加材料，並在材料足夠時啟用。
- [ ] 正式網站部署後完成瀏覽器實際擲骰及合成驗收。
