## 任務

建立登入後雲端模式狀態機、帳號限定快取及伺服器 bootstrap／首次初始化流程。雲端模式只採伺服器權威狀態，不讀取、合併或上傳離線遊戲進度及資產。

## 範圍與禁止

- 只動：
  - Auth 狀態切換、登入／登出／切帳流程、每個 user ID 獨立的雲端快取、bootstrap、首次雲端初始化、載入中／失敗／離線狀態保護、過期請求隔離。
- 不要動：
  - 離線槽位內部實作（T-0003）、偏好欄位同步（T-0005）、擲骰及其他遊戲交易、正式環境 DDL／DML／RLS／grants。
  - 不得把離線存檔合併到雲端；bootstrap 失敗時不得以本機資產冒充雲端狀態。
- 實作前依 Board 規則取得本任務專用 branch／worktree 的人類授權；不得自行建立。

## 驗收條件

- [ ] 雲端登入後固定進入雲端模式，bootstrap 成功前權威操作全部鎖定。
- [ ] 首次登入由伺服器建立符合預設規則的全新雲端狀態，不讀取離線進度或資產。
- [ ] A 帳號登出／切換 B 帳號後，A 的快取、延遲回應及背景請求不能污染 B。
- [ ] 網路中斷或 bootstrap 失敗時明確顯示錯誤並鎖定權威操作，不退回本機計算。
- [ ] 補上首次登入、重複登入、切帳競態、登出及 bootstrap 失敗測試。
- [ ] 補上未授權、跨帳號、重複請求、併發及 rollback 測試；依任務範圍選用適用案例。
- [ ] git diff --check exit 0；相關測試指令與 exit code 記錄於任務紀錄。
