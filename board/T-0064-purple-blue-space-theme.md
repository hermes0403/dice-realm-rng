## 任務

修正 T-0063 背景改版造成的視覺落差，將全站前景元件由翡翠綠改為深紫藍／靛藍色系，搭配不刺眼的淺紫藍星空背景。維持遊戲資訊清晰與既有操作方式。

## 範圍與禁止

- 只修改全站視覺 CSS 色彩、背景裝飾與樣式表快取版本。
- 卡片、按鈕、導覽列、管理面板、輸入框、天氣狀態、骰子展示等元件統一使用紫藍色系。
- 背景使用柔和但明確可辨識的淺紫藍色，不使用大面積純白或近白色；星點與星雲保持低對比。
- 保留文字內容、字體、元件位置尺寸、互動、遊戲邏輯、資料庫與 API。
- 不新增外部圖片、字型或額外網路請求。

## 驗收條件

- [ ] 全站不再殘留原本翡翠綠的主要元件主題色。
- [ ] 卡片、按鈕、導覽列、管理面板、輸入框等主要元件統一為深紫藍／靛藍色。
- [ ] 背景呈現淺紫藍星空感，不會整片泛白，且文字仍清晰易讀。
- [ ] 桌面與手機版的既有排版、元件位置尺寸及互動不變。
- [ ] 不增加外部資源請求；差異僅涉及 style.css、index.html 與本任務紀錄。
- [ ] 完成 CSS 差異檢查與既有 CI。
