## 任務

將天氣骰投入、特殊天氣召喚及天氣轉換改為伺服器權威交易，確保玩家資產與全服天氣狀態一致。

## 範圍與禁止

- 只動：
  - depositWeatherDice()、summonSpecialWeather()、convertWeather()、自動投入偏好、全域天氣狀態／冷卻／貢獻紀錄及相關交易事件。
- 不要動：
  - 擲骰核心、出售／背包、手套、藥水、grant、寵物完整系統或排行榜。
  - 不接受客戶端指定天氣結果、點數、冷卻、貢獻量或骰子扣除結果。
  - 不得以未鎖定的跨玩家讀改寫方式更新全域天氣。
- 實作前依 Board 規則取得本任務專用 branch／worktree 的人類授權；不得自行建立。

## 驗收條件

- [ ] 投入骰子時伺服器驗證持有量、骰子類型、可投入數量及權威貢獻值。
- [ ] 召喚／轉換結果、成本、冷卻與全域天氣更新由伺服器決定。
- [ ] 玩家資產扣除、全域天氣變更及事件同交易提交；失敗完整 rollback。
- [ ] 多玩家同時投入／召喚／轉換時不遺失貢獻、不重複扣資產且不產生競態。
- [ ] 擲骰核心能讀取權威有效天氣狀態；自動投入只依 T-0005 白名單偏好。
- [ ] 補上未授權、跨帳號、重複請求、併發及 rollback 測試；依任務範圍選用適用案例。
- [ ] git diff --check exit 0；相關測試指令與 exit code 記錄於任務紀錄。
