## 任務

將骰子出售及背包擴充改為伺服器權威交易，確保出售數量、售價、玩家金幣與容量上限皆由伺服器驗證及更新。

## 範圍與禁止

- 只動：
  - sellMany() 對應出售 RPC、upgradeBagBtn 對應擴充 RPC、交易冪等、資產事件及前端回傳狀態處理。
- 不要動：
  - 擲骰抽樣核心（T-0006）、手套／藥水／天氣／grant／寵物交易、成就獎勵與排行榜。
  - 不接受客戶端傳入售價、折扣、金幣餘額或擴充後容量。
- 實作前依 Board 規則取得本任務專用 branch／worktree 的人類授權；不得自行建立。

## 驗收條件

- [ ] 伺服器依玩家實際持有骰子 ID／數量計算可出售數量及價格。
- [ ] 不存在超賣、重複出售、負庫存或客戶端偽造金幣入帳。
- [ ] 背包擴充成本、最大容量及扣款由伺服器驗證並原子提交。
- [ ] 重複 request ID 不會重複扣款或增加金幣；併發出售與擲骰不會造成資產競態。
- [ ] 前端只傳送出售／擴充意圖，使用伺服器回傳結果更新畫面。
- [ ] 補上未授權、跨帳號、重複請求、併發及 rollback 測試；依任務範圍選用適用案例。
- [ ] git diff --check exit 0；相關測試指令與 exit code 記錄於任務紀錄。
