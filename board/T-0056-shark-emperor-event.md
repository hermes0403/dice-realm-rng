## 任務

將目前鯊皇活動預覽擴充為可運作的活動系統：提供動態任務序列、依可信遊戲事件累積進度、完成後自動發放鯊皇幣、顯示餘額、管理員額外發放紀錄，以及六種活動寵物圖鑑。活動頁及入口目前維持管理員限定，不擅自公開給一般玩家。

## 範圍與禁止

- 只動：鯊皇活動前端頁面與樣式、必要的遊戲事件整合、必要的 Supabase migration／RPC／RLS、活動測試與本任務 Board 紀錄。
- 任務系統初始提供 25 項，採可追加的資料結構，不得把任務數量寫死為 25。
- 任務依序解鎖：只顯示／計算目前任務；達標後自動領取該項鯊皇幣並解鎖下一項，不允許跳關或預先累計未解鎖任務。
- 遊戲行為自動累計任務進度，涵蓋擲骰、寵物合成與品質、藥水合成、寵物持有／出售、天氣召喚、寵物變異及指定稀有度骰子。
- 鯊皇幣餘額與獎勵必須由後端權威處理，具備交易原子性及重複請求冪等性；不得信任客戶端提交的進度、餘額或獎勵。
- 六種活動寵物需加入收藏圖鑑及寵物資料查找，但不得加入一般合成池。
- 龍晶蛋目前僅保留庫存欄位與數量顯示；取得／使用規則未確認前，不實作隨機抽取或扣除。
- 活動與任務面板視覺採黑曜石質感、暗紅與金色光效、鯊魚元素、金屬邊框及深色科幻風。
- 目前活動入口及頁面維持管理員限定；不得擅自改為全玩家公開。
- 不要改動既有骰子機率、一般金錢、一般寵物收益、天氣觸發條件或其他無關遊戲機制。
- 不得修改 main；不得把 T-0034 的預覽限制改寫成已授權真實交易功能。
- Supabase migration 可在本任務範圍內新增，但不得把憑證或秘密寫入 repository；部署前確認正確專案與 migration 影響。

## 獎勵與待確認事項

- 獎勵規格：第 1～9 項每項 1 鯊皇幣；第 10～25 項每項 1.5 鯊皇幣，完成 25 項共可獲得 33 鯊皇幣。管理員額外發放需獨立記錄，並計入玩家餘額。
- 龍晶蛋的取得／兌換規則尚未從既有紀錄確認；不得自行假設以鯊皇幣購買或由任務發放，目前只保留庫存欄位，不實作隨機抽取。
- 六種龍晶蛋寵物機率依既有預覽設定：45%、30%、14.6%、8.5%、1.5%、0.4%；需先核對現行活動預覽資料與實際寵物 ID，不可只憑名稱猜測。

## 驗收條件

- [ ] 25 項初始任務可依序完成，後續可新增任務而不需修改固定長度限制。
- [ ] 未解鎖任務不顯示、不計算進度；完成目前任務後自動發獎並解鎖下一項。
- [ ] 同一任務完成事件重送、併發請求或重新登入，不會重複發放鯊皇幣。
- [ ] 玩家餘額能正確載入、更新及跨裝置持續保存。
- [ ] 六種活動寵物可由寵物 ID 正確查找、顯示收益及出現在收藏圖鑑，且不會進入一般合成池。
- [ ] 龍晶蛋目前只顯示庫存，不會在未確認規則前進行隨機抽取或扣除。
- [ ] 活動入口與頁面仍只有管理員可見／進入。
- [ ] 活動面板與任務面板符合指定黑曜石、暗紅金色、鯊魚科幻視覺。
- [ ] 不影響原有擲骰、合成、藥水、天氣、寵物、存檔與一般貨幣流程。
- [ ] 完成前端測試、後端 RPC／RLS 測試及必要整合測試；記錄實際指令與 exit code。
- [ ] 不部署到 GitHub Pages，除非另有明確部署授權；Supabase 正式環境操作依實際授權與驗證執行。
