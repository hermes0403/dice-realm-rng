## 任務

修正全站紫藍主題完成後，部分按鈕仍保留原本色彩或彼此色調差異過大的問題，讓一般按鈕、主要操作、次要操作、導覽按鈕與特殊入口都融入紫藍星空主題。

## 範圍與禁止

- 只調整 CSS 配色、邊框、陰影、互動狀態及樣式表快取版本。
- 一般按鈕統一為靛藍／紫藍漸層；主要操作使用較明亮的藍紫色；次要操作使用較深的藍紫色。
- 導覽列維持透明未選取狀態，選取狀態改為藍紫色。
- 危險操作保留辨識度，但改為協調的暗紫紅色。
- 修正圖鑑分類、活動入口及藥水自動加入等特殊按鈕的色調。
- 保留文字、排版、尺寸、位置、功能、事件與資料流程，不改遊戲邏輯。
- 不新增外部資源或網路請求。

## 驗收條件

- [ ] 一般按鈕不再出現與紫藍主題衝突的主要底色。
- [ ] 主要、次要、選取、危險按鈕仍可清楚區分。
- [ ] 導覽列與特殊入口按鈕配色一致。
- [ ] hover、active、disabled 狀態可辨識且文字清晰。
- [ ] 不改動按鈕尺寸、位置、互動及遊戲功能。
- [ ] 完成 CSS 差異檢查與既有 CI。
