## 任務

將成就進度、解鎖、每日任務、每日重置及獎勵領取改為伺服器根據可信遊戲事件計算，避免客戶端偽造完成狀態或重複領獎。

## 範圍與禁止

- 只動：
  - checkAchievements()、checkDailyReward()、ensureDailyQuest() 對應的伺服器邏輯、可信事件消費、任務進度、重置與獎勵領取。
- 不要動：
  - 擲骰及各交易本身、寵物系統本身、排行榜查詢或舊資料最終退場。
  - 不接受客戶端提交的完成進度、解鎖旗標、任務日期、獎勵數量或已領取狀態。
- 實作前依 Board 規則取得本任務專用 branch／worktree 的人類授權；不得自行建立。

## 驗收條件

- [ ] 成就及每日任務進度只由可信伺服器事件／權威狀態計算。
- [ ] 解鎖條件、時間戳及每日重置時間由伺服器時間決定。
- [ ] 獎勵入帳與唯一領取紀錄同交易提交；同一獎勵重複請求不會重複發放。
- [ ] 客戶端偽造完成旗標、進度數字或日期不能解鎖或領取獎勵。
- [ ] P1～P4 各權威交易事件均有明確事件契約及對應任務處理測試。
- [ ] 補上未授權、跨帳號、重複請求、併發及 rollback 測試；依任務範圍選用適用案例。
- [ ] git diff --check exit 0；相關測試指令與 exit code 記錄於任務紀錄。
