## 任務

改造道具工坊的配方材料投入流程。玩家可從自己的骰子背包選擇配方需要的骰子，確認後消耗背包中的對應骰子並投入配方材料槽。已投入材料必須持久保存，切換頁面、重新登入或重新載入後仍保留；材料全部到齊後才可合成。

本任務先以既有「時序結晶」配方為範圍，保留原材料種類、合成結果、效果及使用冷卻，不改動其他配方或道具經濟規則。

## 既有配方與固定規則

- 時序骰子 ×1
- 虛空骰子 ×1
- 故障骰子（任一故障系列）×1
- 合成結果：時序結晶。
- 使用效果：延長下一次天氣持續時間 20%。
- 可重複使用，每次使用後冷卻 1 小時。

## 介面要求

- 每個未完成配方以精簡單列呈現材料名稱、投入進度（例如 0/1、1/1）及「添加」按鈕。
- 點擊「添加」開啟玩家自己的骰子背包選擇介面，只顯示符合該材料條件且目前可投入的骰子。
- 玩家選擇並確認後，從背包消耗一顆對應骰子，並將其記入該配方材料槽。
- 已投入的材料顯示完成狀態；已滿額材料不再顯示添加按鈕。
- 多個配方預設收合，點擊配方標題才展開；保留目前工坊深色科幻視覺。
- 配方材料全部到齊後才啟用「合成」。
- 合成完成後隱藏材料清單，改為精簡的已合成道具卡片，顯示「已合成」、效果說明及「使用時序結晶」按鈕。
- 不顯示「持有數量」或「使用冷卻」欄位標籤；使用按鈕下方僅顯示「可重複使用，每次使用後冷卻 1 小時。」冷卻期間按鈕停用並顯示倒數。

## 持久化與安全要求

- 材料投入紀錄必須綁定目前登入玩家，重新登入、重新載入及切換頁面後正確還原。
- 投入操作必須避免重複點擊、重送請求或併發造成重複扣除／重複投入；成功回應前不可先顯示已完成。
- 必須確認背包確實持有符合條件的骰子，且只扣除一顆；不得接受客戶端偽造的持有數量或材料完成狀態。
- 保存與扣除流程需避免材料已扣除但投入紀錄遺失，或投入紀錄成功但背包未扣除的狀態不一致。
- 不修改其他玩家資料作測試；涉及正式資料庫變更時先檢查既有 schema、RLS、RPC 權限及回復方式，僅在本任務明確授權範圍內操作。
- 不新增高頻輪詢、Realtime 訂閱或不必要的雲端讀寫。

## 驗收條件

- [ ] 每種材料的添加按鈕只開啟符合條件的玩家背包選項。
- [ ] 確認投入後，背包正確扣除一顆骰子，配方材料進度正確增加。
- [ ] 任一材料未到齊時，合成按鈕保持停用；全部到齊後才可合成。
- [ ] 投入材料在切換頁面、重新整理、登出及重新登入後仍正確保存，且只屬於原玩家。
- [ ] 重複點擊、重送及併發操作不會重複扣除或重複投入。
- [ ] 合成後材料清單隱藏，已合成卡片、效果文字及使用按鈕顯示正確。
- [ ] 時序結晶仍延長下一次天氣 20%，可重複使用且每次使用冷卻 1 小時。
- [ ] 冷卻期間按鈕停用並顯示倒數；冷卻結束後恢復可用。
- [ ] 手機與桌面版版面正常，配方收合／展開及背包選擇流程可操作。
- [ ] 相關語法、回歸與安全測試通過；記錄實際命令及 exit code。
- [ ] GitHub Actions 與 GitHub Pages 部署成功，並以線上版本驗證完整流程。
