## 任務

在《骰界 RNG》管理員面板新增指定成員手動發放 XP 功能，並建立完整的公會 XP 獲得紀錄。公會 XP 仍是公會共享經驗；任務紀錄必須標明是哪位成員完成任務並使其公會獲得 XP，不能把公會共享獎勵誤寫成每位成員各自獲得相同 XP。

## 範圍與禁止

- 只動：
  - 管理員面板：選擇玩家、輸入 XP 數量、填寫發放原因，將 XP 發放至該玩家所屬公會。
  - 管理員面板：查看最近的 XP 獲得紀錄，至少顯示成員、公會、任務／來源、XP 數量、時間；手動發放另顯示管理員與原因。
  - 資料庫：新增統一 XP 紀錄帳本，所有自動任務發放與管理員手動發放都必須與 XP 入帳在同一交易中寫入。
  - 既有每日任務：每日登入 15 XP、在線每 30 分鐘 10 XP、擲骰每 1,000 次 15 XP、全員每日登入公會額外 20 XP；不得改動既有條件、數值、重複完成規則或公會升級門檻。
  - 新增資料庫、權限及回歸測試，並確認查詢紀錄不新增高頻輪詢。

- 不要動：
  - 不修改公會 4 人上限、既有任務 XP 數值、每日重置時間或升級獎勵。
  - 不允許前端直接寫入 XP、指定發放對象或任務完成紀錄；所有發放都必須由伺服器驗證。
  - 不把管理員手動發放記成一般任務完成。
  - 全員登入 +20 XP 是公會整體獎勵，需記錄觸發成員與當時成員快照，不可顯示成每位成員各自獲得 +20 XP。
  - 不新增高頻輪詢或不必要的 Realtime 訂閱。

## 驗收條件

- [x] 管理員可從現有玩家名單選擇一位成員，輸入正整數 XP 與必填原因，發放至其所屬公會；沒有公會的玩家不可發放。
- [ ] 手動發放由伺服器驗證管理員身份、目標成員及公會歸屬；玩家不能呼叫相同功能替自己或他人加 XP。
- [ ] 所有自動任務發放（登入、在線每輪、擲骰每輪、全員登入獎勵）都寫入統一雲端紀錄，並與 XP 入帳同交易完成；重試及併發不得重複記錄或重複發放。
- [ ] 每筆個人任務紀錄包含公會、成員、任務名稱／來源、XP 數量及時間；全員登入獎勵包含觸發成員、當時成員快照及公會獎勵範圍。
- [ ] 管理員紀錄畫面可載入最近紀錄，並清楚區分任務 XP 與管理員手動 XP；手動紀錄包含管理員、原因、目標成員及發放時間。
- [ ] 手動 XP 發放會正確觸發既有公會升級及升級獎勵流程，不會繞過 Lv.20 上限或重複發放升級獎勵。
- [ ] RLS、RPC／Edge Function 權限及資料表存取安全；一般玩家無法讀取管理員完整紀錄或寫入紀錄帳本。
- [ ] 不新增高頻網路請求；相關單元、資料庫交易、重複請求、未授權、跨公會、回滾及既有公會回歸測試通過。
- [ ] 手機與桌面管理員面板正常；git diff --check exit 0，記錄實際測試命令與結果。
