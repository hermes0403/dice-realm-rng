## 任務

將手套購買、合成及裝備狀態切換改為伺服器權威交易，並確保手套效果可由擲骰核心讀取。

## 範圍與禁止

- 只動：
  - purchaseGlove()、craft() 中手套相關路徑、裝備切換、配方／價格／上限驗證、手套效果狀態及交易事件。
- 不要動：
  - 骰子出售／背包擴充、藥水、天氣、grant、寵物合成及成就系統整體實作。
  - 不接受客戶端指定配方結果、手套屬性、價格或獎勵；前端不得補發成就獎勵。
- 實作前依 Board 規則取得本任務專用 branch／worktree 的人類授權；不得自行建立。

## 驗收條件

- [ ] 購買／合成由伺服器驗證材料、金幣、配方、持有上限及裝備規則。
- [ ] 扣除成本、產生手套、裝備狀態與事件同交易提交。
- [ ] 手套加成及有效狀態由權威資料維護，擲骰 RPC 能讀取且不接受客戶端覆寫。
- [ ] 重複請求、併發購買及材料不足不會造成重複入帳或部分扣除。
- [ ] 前端不再直接寫入手套資產或自行補發購買／合成成就獎勵。
- [ ] 補上未授權、跨帳號、重複請求、併發及 rollback 測試；依任務範圍選用適用案例。
- [ ] git diff --check exit 0；相關測試指令與 exit code 記錄於任務紀錄。
