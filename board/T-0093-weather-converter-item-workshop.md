## 任務

將原有「天氣手套」調整為可合成的「天氣轉換器」，並新增獨立的「道具工坊」入口，讓玩家能在不混淆手套與道具的情況下取得及使用天氣轉換器。

## 範圍與禁止

- 天氣手套改名為「天氣轉換器」，並從「手套工坊」移至新增的「道具工坊」。
- 「道具工坊」入口放在「藥水工坊」旁。
- 天氣轉換器合成材料／條件依棒子指定的五種天氣骰子稀有度：雨 1/9,800、雪 1/5,300、打雷 1/7,560、水晶 1/1,780、地獄 1/2,222。實作前先核對現有配方資料結構，按既有合成系統表示，不得自行改寫成抽取機率或更動數值。
- 已經擁有舊「天氣手套」的玩家必須保留既有持有權及每小時施放一次天氣的能力；不得要求既有玩家重新合成，不得清除或重置其存檔。
- 尚未擁有天氣手套／轉換器的玩家，必須透過新配方合成取得。
- 移除天氣轉換器原有速度與運氣加成，只保留每小時施放一次天氣的能力。
- 優先沿用原道具 ID／持有欄位及現有存檔格式；若必須遷移 ID，必須採向後相容方式，確保舊持有資料可辨識且不會重複發放。
- 不新增不必要的 Supabase 查詢、輪詢或寫入；若涉及伺服器交易，沿用現有授權與冪等交易流程，不得只在客戶端偽造合成成功。
- 不改動其他手套、藥水、天氣效果、天氣持續時間或施放冷卻規則。

## 驗收條件

- [ ] 導覽／工坊入口在「藥水工坊」旁新增「道具工坊」。
- [ ] 手套工坊不再顯示天氣手套／天氣轉換器；道具工坊顯示天氣轉換器。
- [ ] 顯示名稱統一為「天氣轉換器」，不再以「天氣手套」作為玩家可見名稱。
- [ ] 合成材料／條件精確符合雨 1/9,800、雪 1/5,300、打雷 1/7,560、水晶 1/1,780、地獄 1/2,222。
- [ ] 原本已持有天氣手套的玩家在更新後仍持有天氣轉換器，不需重新合成，原有施放權限保留。
- [ ] 未持有者不能直接取得；只能透過新配方合成取得。
- [ ] 速度與運氣加成已移除，天氣施放能力仍保留且冷卻為每小時一次。
- [ ] 合成消耗、重複請求、存檔載入及重新登入流程通過測試，沒有重複扣料或重複發放。
- [ ] 舊玩家存檔相容，沒有重置、刪除或覆蓋既有道具資料。
- [ ] 版本與 PWA 快取版本同步遞增 0.01；GitHub Pages 部署完成並驗證線上版本。
