## 任務

依棒子提供的新數值，更新寵物重量收益倍率，並將「遊戲更新日誌」導覽頁改為「寵物資訊」頁，集中說明重量、外觀變異及天氣變異的收益加成。

## 範圍與禁止

- 只動：
  - `systems/pet-skills.js`：更新寵物重量倍率分級。
  - `config.js`：將導覽名稱「遊戲更新日誌」改為「寵物資訊」。
  - `index.html`、`style.css`：將原更新日誌內容替換為寵物資訊，加入重量倍率表及各變異獨立面板。
  - 必要的測試與前端快取版本。
- 重量倍率必須使用以下分級，區間端點均包含：
  | 重量 | 倍率 |
  |---|---:|
  | 1–99 kg | ×1.0 |
  | 100–200 kg | ×1.2 |
  | 201–500 kg | ×1.5 |
  | 501–1,000 kg | ×1.8 |
  | 1,001–2,000 kg | ×2.0 |
  | 2,001–5,000 kg | ×2.5 |
  | 5,001–10,000 kg | ×2.8 |
  | 10,001–40,000 kg | ×3.0 |
  | 40,001–100,000 kg | ×3.5 |
  | 100,001–500,000 kg | ×3.8 |
  | 500,001–3,000,000 kg | ×4.0 |
  | 3,000,001 kg 以上 | ×4.5 |
- 保留現有收益計算順序：重量倍率加上天氣變異加成，再乘外觀變異倍率；不得因顯示頁改版而改變計算語意。
- 外觀變異倍率：無變異 ×1、黃金 ×1.2、鑽石 ×1.6、彩虹 ×2。
- 天氣變異加成：雨 +1.2、雪 +1.3、打雷 +1.4、水晶 +1.7、地獄 +2。現有 `PET_MUTATIONS` 數值已符合要求，除非測試證明不一致，否則不修改其資料。
- 寵物資訊頁每種外觀變異與天氣變異各自使用獨立框格；雨藍色、雪白／米白、打雷亮黃色、水晶紫色、地獄紅色；彩虹使用完整彩虹漸層色帶。重量倍率可使用清晰表格。
- 不要動：寵物重量生成分布、寵物基礎收益、變異生成機率／繼承規則、玩家存檔、寵物資產、Supabase schema／資料／RPC、其他遊戲經濟規則。
- 不新增 Supabase 查詢、Realtime 訂閱、輪詢或雲端寫入。

## 驗收條件

- [ ] 12 個重量區間及所有邊界值均回傳正確倍率，3,000,001 kg 以上固定為 ×4.5。
- [ ] 寵物被動收益及相關裝備收益實際套用新重量倍率；天氣加成仍為加法，外觀變異仍為乘法。
- [ ] 既有雨、雪、打雷、水晶、地獄加成數值與顯示完全一致。
- [ ] 導覽顯示「寵物資訊」，點擊後不再顯示舊版更新日誌。
- [ ] 無變異、黃金、鑽石、彩虹，以及五種天氣變異均有各自獨立框格；顏色符合指定主題，彩虹顯示完整漸層。
- [ ] 手機與桌面版均可閱讀，重量表不造成水平溢出。
- [ ] 更新既有收益測試並新增邊界測試；相關自動化測試及快取版本檢查通過。
- [ ] 沒有改動玩家資料或增加任何 Supabase 流量。
