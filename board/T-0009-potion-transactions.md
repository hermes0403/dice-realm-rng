## 任務

將藥水材料庫存、合成、使用、效果期限及消耗改為伺服器權威管理，並提供擲骰核心安全讀取及消耗效果的介面。

## 範圍與禁止

- 只動：
  - craftPotion()、usePotion()、材料／藥水庫存、配方、效果槽位／到期時間、藥水材料自動添加偏好及可信交易事件。
- 不要動：
  - 手套、天氣、grant、寵物完整系統、成就整體實作或排行榜。
  - 不接受客戶端傳入材料數量、合成結果、藥水效果強度、剩餘次數或到期時間。
  - Owner 已確認移除的 update_player_potions(uuid, integer) 不得重新引入為任意目標使用者增減介面。
- 實作前依 Board 規則取得本任務專用 branch／worktree 的人類授權；不得自行建立。

## 驗收條件

- [ ] 合成配方、材料扣除、藥水入帳及事件由伺服器驗證並原子提交。
- [ ] 使用藥水時由伺服器維護效果槽位、期限、次數及替換規則。
- [ ] 擲骰核心只讀取伺服器權威藥水狀態，並在擲骰交易中原子消耗一次性效果。
- [ ] 自動添加只依 T-0005 偏好及伺服器材料容量／配方規則處理，不會憑空生成材料。
- [ ] 所有 RPC 驗證 auth.uid() 與目標玩家一致，固定安全 search_path，並限制 function EXECUTE ACL。
- [ ] 補上未授權、跨帳號、重複請求、併發及 rollback 測試；依任務範圍選用適用案例。
- [ ] git diff --check exit 0；相關測試指令與 exit code 記錄於任務紀錄。
