## 任務

將管理員面板的 XP 功能集中成獨立大分類，內含「最近 100 筆 XP 紀錄」、「發放 XP」、「玩家累積 XP」三個子區塊。手動發放必須選擇公會，不能選擇玩家；玩家累積 XP 顯示每位玩家自己的任務 XP 總和。

## 範圍與禁止

- XP 管理成為管理員導覽中的獨立大分類，不再混在玩家資料或一般管理操作。
- 大分類內有三個可獨立展開的子區塊：
  - 最近 100 筆 XP 紀錄：保留原本完整來源、成員、公會、時間、管理員及原因。
  - 發放 XP：選擇公會、輸入 XP、填寫原因，將 XP 加到所選公會共享經驗。
  - 玩家累積 XP：逐位玩家列出個人累積 XP、目前公會、紀錄數及最近獲得時間，按累積 XP 由高至低排序。舊紀錄無法還原加成後數量時，以「≥」標示可核對下限並顯示筆數。
- 個人累積只計入可歸屬到該玩家的 XP；全員登入 +20 及新制管理員公會整體發放均屬公會級獎勵，不可錯算到某一位玩家。
- 後端必須重新驗證管理員、目標公會、金額、原因及請求識別碼；公會發放與帳本同交易寫入，重試不得重複發放。
- 不新增高頻輪詢或 Realtime 訂閱。

## 不要動

- 不修改既有每日任務條件與 XP 數值、全員登入獎勵、升級門檻及升級獎勵。
- 不改動既有 XP 帳本紀錄或對玩家補發任何 XP。
- 不允許前端直接寫入公會 XP 或帳本。

## 驗收條件

- [ ] XP 管理已成為獨立大分類，內含三個指定子區塊；自動化結構測試通過，仍待實際手機／桌面操作驗收。
- [x] 最近 100 筆 XP 紀錄保留原本欄位，公會整體發放清楚標示為「全公會」。
- [x] 發放 XP 只能選擇公會；選定公會後輸入正整數 XP 及原因即可發放。
- [x] 手動發放使用服務端權限驗證、交易式寫入及冪等識別碼；一般玩家不可呼叫。
- [x] 玩家累積 XP 顯示每位玩家個人任務 XP 總和，包含零 XP 玩家；不把全員登入 +20 或公會整體手動發放算到單一玩家。
- [x] 公會名單與玩家累積資料由單次管理 API 載入，僅在展開區塊或手動刷新時載入。
- [x] XP 專項與完整回歸測試通過；部署後確認 GitHub Pages 成功。
