## 問題

天堂藥水抽取完成後，擲骰流程原本每抽都將 `angelMode` 清空，即使 `angelCharges` 尚有剩餘。後續抽次因此可能被當成天堂 I，造成天堂 II 待抽數出現錯誤機率池。

## 修正

- 保留目前天堂模式，直到最後一個待抽次數消耗完畢。
- 同一種類的天堂藥水可累加待抽次數。
- 尚有另一種類天堂藥水待抽時，阻止使用不同種類覆蓋模式，避免混合抽數產生錯誤。
- 雲端存檔已將整個 `potions` 物件納入存檔 payload；載入流程未主動清空 `angelMode`。本次不新增資料庫欄位、RPC 或額外查詢。

## 驗收

- [x] 天堂 I 低運氣機率池含彗星骰子固定 20%。
- [x] 天堂 II 低運氣機率池不含彗星骰子，虛空骰子固定 17%。
- [x] 多抽數消耗後保留天堂模式，最後一抽才清空。
- [x] 待抽天堂藥水期間不可切換另一種模式。
- [ ] 天堂機率專項測試與擲骰回歸測試通過。
- [ ] GitHub Pages 部署完成並驗證線上版本。

## 注意

既有玩家若在舊版程式已經發生「`angelCharges` 大於 0、但 `angelMode` 已被清空」，舊程式沒有留下原本模式的紀錄，無法從現有資料還原該批抽數原本屬於天堂 I 或 II。新版會避免再次發生。
