## 任務

修正首頁管理員活動倒數出現「剩餘 NaN:NaN 分鐘」的問題；並改善寵物合成區「我的寵物」出售視窗，讓玩家可依寵物稀有度及每秒收益排序，且每隻寵物都能辨識其外觀／天氣變異。

## 範圍與禁止

- 只動：全服活動時間解析與倒數顯示、寵物出售視窗的排序控制／排序邏輯／變異標籤，以及必要測試。
- 不要動：倍率設定 API、寵物售價、出售交易 RPC、寵物資料結構、變異生成規則、玩家資產或其他遊戲頁面。
- 排序只改變畫面順序，不改變玩家持有寵物的實際順序或資料。
- 保留出售勾選狀態；排序變更後不可意外清除已勾選寵物。

## 驗收條件

- [x] 活動倒數可正確解析 ISO 時間、Unix 秒／毫秒及數字字串；無效時間不可顯示 NaN。
- [x] 寵物出售視窗提供稀有度低到高、稀有度高到低、每秒收益高到低及每秒收益低到高排序。
- [x] 排序後勾選狀態保留，出售交易仍使用原本伺服器 RPC／離線流程。
- [x] 出售視窗顯示寵物的黃金、鑽石、彩虹及雨／雪／打雷／水晶／地獄等實際變異，並沿用各變異顏色。
- [x] 無變異寵物不顯示空白變異列；多個變異完整顯示且不重複。
- [x] 完成倒數及出售清單排序／變異顯示自動化測試。
